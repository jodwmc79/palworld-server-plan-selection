## 朋友连不上？九成是 8211 端口没放行

幻兽帕鲁默认端口是 **8211，协议是 UDP**。这两个信息必须同时对上，只放行 TCP 8211 一样连不上。

雨云面板服和游戏云 VPS 都在控制台做 NAT 端口映射：新建一条规则，把内网 8211 映射出去，然后把映射后的公网地址和端口发给朋友。面板服这一步几秒钟就好，不用碰系统防火墙。游戏云 VPS 如果自己装了系统，还要在 Windows 防火墙或 Linux 的 ufw 里放行 UDP 8211。

客户端那边就是「IP:端口」的格式，有密码的服会再弹一次密码框。

还有一条限制值得提前说：PS5 和 Xbox 不能通过 IP 直连，只能从公共服务器列表里加入，也不支持 Tailscale 这类组网工具。朋友里有主机玩家的话，把服务器设为带密码的半私密服，让他们从列表里找，是唯一可行的方式。

## 跑两天就卡：内存泄漏和两个兜底方案

幻兽帕鲁服务端有内存泄漏的老问题，跑久了占用持续上涨，最后卡顿甚至崩服。这跟买哪家服务器没关系，换成谁都一样。

**兜底一：加虚拟内存（SWAP）**。8G 的机器额外开 8–12G SWAP，Windows 在控制面板里调虚拟内存大小，Linux 用 `fallocate` 建 swapfile，几分钟的事。作用是内存吃满时不至于直接崩，代价是那部分数据走硬盘，会慢一些。

**兜底二：自动重启脚本**。内存占用超过 90% 自动重启帕鲁进程，回档大约 10 秒，玩家基本无感，能让服务器稳定跑几十个小时。

根本的解决办法还是把内存配够，直接上 16G，这两个方案就变成保险而不是日常依赖。

## 配置文件：先复制模板，再改参数

这一步很多人踩坑：直接编辑 `DefaultPalWorldSettings.ini` 是无效的。正确做法是打开 `DefaultPalWorldSettings.ini`，把里面的内容整体复制到 `PalWorldSettings.ini`，在后者上改。

面板服的文件管理里，路径是 `pal/Pal/Saved/Config/LinuxServer/PalWorldSettings.ini`。Linux VPS 上是 `/home/ubuntu/Steam/steamapps/common/PalServer/Pal/Saved/Config/LinuxServer/PalWorldSettings.ini`。

值得改的就几个：`ServerPlayerMaxNum`（最大玩家数，小服设 4–8 就够，别留默认的 32）、`ExpRate`（经验倍率，休闲玩 2.0–3.0）、`PalCaptureRate`（捕获率，1.5–2.0 明显舒服）、`DeathPenalty`（死亡惩罚，`None` 不掉落，`All` 全掉）、`ServerPassword` 和 `AdminPassword`（都设上，管理员密码用强密码）。

改完保存，重启实例生效。游戏里按回车输入 `/adminpassword 你的密码` 拿到管理权限，之后能用 `/Shutdown`、`/Restart`、`/Kick`、`/Ban`。
